# 조은일 — 2D 애니메이션 포트폴리오

Google Sites의 공개 콘텐츠를 옮긴 정적 포트폴리오입니다. HTML, CSS, JavaScript와 로컬 이미지만 사용하며 빌드나 서버 프로그램이 필요하지 않습니다.

- `index.html`: 대표 작품, 4개 애니메이션 작업, 사용 도구, 연락처
- `about.html`: 기존 소개 페이지와 미작성 항목 보존
- `projects.html`: 기존 프로젝트 페이지와 미작성 항목 보존
- `assets/`: 원본 페이지 이미지와 실제 외부 뷰어에서 캡처한 작품 이미지

작품 뷰어는 기존 `*.millialdo82.chatgpt.site` 주소를 새 창에서 엽니다. 이 저장소에는 뷰어 구현이나 Unity 프로젝트가 포함되지 않습니다.

GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시하도록 설정합니다. `.nojekyll`이 있어 별도 Jekyll 처리를 하지 않습니다. 모든 내부 경로가 상대 경로이므로 프로젝트 저장소 하위 주소에서도 동작합니다.

원본: https://sites.google.com/view/heero03portfolio/홈

콘텐츠·이미지·애니메이션의 기존 권리는 원 권리자에게 있습니다. 이 저장소는 별도의 재사용 라이선스를 부여하지 않습니다.
