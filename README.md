# 조은일 — 2D 애니메이션 포트폴리오

Google Sites의 공개 콘텐츠를 옮긴 정적 포트폴리오입니다. HTML, CSS, JavaScript와 로컬 이미지만 사용하며 빌드나 서버 프로그램이 필요하지 않습니다.

- `index.html`: 대표 작업물, 4개 애니메이션 작업, 사용 도구, 연락처
- `about.html`: 소개, skills, 업무 경력, 학력
- `projects.html`: Goddess order 영상과 project 'ZERO' 이미지
- `assets/`: 사용자가 제공한 이미지와 실제 외부 뷰어에서 캡처한 작업물 이미지

작업물은 SSP → Spine pixel → Spine illustration → Spine gacha 순서입니다. 대표 작업물은 캐릭터 가챠 연출입니다. 일반 PC에서는 페이지가 열리면 기존 `*.millialdo82.chatgpt.site` 뷰어 네 개를 자동으로 불러옵니다. 모바일·터치 기기 또는 폭 900px 이하로 연 페이지에서는 미리보기를 먼저 표시하고, ‘여기서 재생’이나 전체화면을 누른 작업물 하나만 불러옵니다. 다른 작업물을 선택하면 이전 뷰어를 종료하여 동시 실행을 막습니다. 이 정책은 페이지를 여는 시점에 정하므로 화면 회전이나 전체화면 전환으로 바뀌지 않습니다. ‘재생 종료’로 멈춘 작업물은 ‘여기서 재생’으로 다시 불러올 수 있습니다. 개별 Unity 뷰어도 데이터와 메모리를 많이 사용하므로 모든 휴대전화에서 실행을 보장하지는 않습니다.

뷰어는 PC에서 Full HD(1920×1080), 한 개씩 재생하는 환경에서는 1280×720의 고정 크기로 준비하고, 카드 안에서는 비율을 유지해 축소합니다. 고해상도 화면에서는 외부 뷰어가 자신의 픽셀 배율에 따라 더 큰 그리기 해상도를 사용할 수 있습니다. 고정 크기는 전체화면 전환 시 기존 Unity 글자가 흐려지던 현상을 피하고, 모바일의 작은 화면 크기는 그리기 부담을 줄입니다. 기존 외부 뷰어와 Unity 장면은 수정하지 않습니다.

전체화면 전환과 복귀는 같은 뷰어를 유지합니다. 브라우저가 전체화면을 지원하지 않으면 페이지 안에서 크게 펼칩니다. 전체화면 닫기 버튼으로 돌아올 수 있습니다. ‘재생이 안 되나요?’에는 다시 불러오기와 원래 주소 링크가 있습니다. JavaScript가 꺼져 있어도 원래 주소에 접근할 수 있습니다.

프로젝트의 YouTube 영상은 별도의 외부 임베드이며 자동 재생하지 않습니다. 뷰어와 영상에는 인터넷 연결 및 외부 서비스 이용 가능 상태가 필요합니다. 이 저장소에는 뷰어 구현이나 Unity 프로젝트가 포함되지 않습니다.

GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시하도록 설정합니다. `.nojekyll`이 있어 별도 Jekyll 처리를 하지 않습니다. 모든 내부 경로가 상대 경로이므로 프로젝트 저장소 하위 주소에서도 동작합니다.
