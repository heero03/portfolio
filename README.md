# 조은일 — 2D 애니메이션 포트폴리오

Google Sites의 공개 콘텐츠를 옮긴 정적 포트폴리오입니다. HTML, CSS, JavaScript와 로컬 이미지만 사용하며 빌드나 서버 프로그램이 필요하지 않습니다.

- `index.html`: 대표 작업물, 4개 애니메이션 작업, 사용 도구, 연락처
- `about.html`: 소개, skills, 업무 경력, 학력
- `projects.html`: Goddess order 영상과 project 'ZERO' 이미지
- `assets/`: 사용자가 제공한 이미지와 실제 외부 뷰어에서 캡처한 작업물 이미지

작업물은 SSP → Spine pixel → Spine illustration → Spine gacha 순서입니다. 대표 작업물은 캐릭터 가챠 연출입니다. 페이지가 열리면 기존 `*.millialdo82.chatgpt.site` 뷰어 네 개를 자동으로 불러옵니다. 각 뷰어는 독립적으로 유지되며 ‘재생 종료’는 해당 작업물만 종료합니다. 종료한 작업물은 ‘여기서 재생’으로 다시 불러올 수 있습니다. 첫 방문은 네 Unity 빌드의 다운로드와 초기화가 필요하므로 데이터와 메모리 사용량이 큽니다.

뷰어는 처음부터 Full HD(1920×1080) 크기로 준비하고, 카드 안에서는 비율을 유지해 축소합니다. 고해상도 화면에서는 외부 뷰어가 자신의 픽셀 배율에 따라 더 큰 그리기 해상도를 사용할 수 있습니다. 전체화면 전환 시 작은 화면에서 생성한 Unity 글자가 확대되어 흐려지던 현상을 해결하면서 기존 외부 뷰어와 Unity 장면은 수정하지 않습니다.

전체화면 전환과 복귀는 같은 뷰어를 유지합니다. 브라우저가 전체화면을 지원하지 않으면 페이지 안에서 크게 펼칩니다. 전체화면 닫기 버튼으로 돌아올 수 있습니다. ‘재생이 안 되나요?’에는 다시 불러오기와 원래 주소 링크가 있습니다. JavaScript가 꺼져 있어도 원래 주소에 접근할 수 있습니다.

프로젝트의 YouTube 영상은 별도의 외부 임베드이며 자동 재생하지 않습니다. 뷰어와 영상에는 인터넷 연결 및 외부 서비스 이용 가능 상태가 필요합니다. 이 저장소에는 뷰어 구현이나 Unity 프로젝트가 포함되지 않습니다.

GitHub Pages는 `main` 브랜치의 루트(`/`)를 게시하도록 설정합니다. `.nojekyll`이 있어 별도 Jekyll 처리를 하지 않습니다. 모든 내부 경로가 상대 경로이므로 프로젝트 저장소 하위 주소에서도 동작합니다.
